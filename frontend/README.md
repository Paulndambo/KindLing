# 🔥 Kindling

**Kindling** is an AI-powered adaptive 1-on-1 tutoring application designed to provide personalized, private-school-quality teaching to every child. Powered by **Google Gemini AI**, Kindling dynamically adjusts lesson pacing, difficulty, and visual or verbal explanations in real-time based on student responses.

---

## ✨ Features

- 🎓 **Interactive Live Lessons**: Real-time, streaming AI chat powered by Gemini (`gemini-2.0-flash`) using `@google/genai`.
- 🧠 **Adaptive AI Tutor**: Kindling observes student responses, offers gentle hints, adjusts challenge levels, and reinforces conceptual understanding instead of just giving answers.
- 📚 **Custom Subject & Topic Management**: Create custom subjects (Math, Biology, Coding, Languages, etc.) and add specific topics to tailor learning paths.
- 📊 **Family Dashboard**: Track student progress, review mastery maps, monitor confidence trends, and view plain-language weekly notes generated by the tutor.
- 🎛️ **Live Tutor Tools**: Toggle accessibility and teaching options on the fly (e.g., read aloud, visual models, extra encouragement, live hint generation).
- 💬 **Scroll-Locked Chat Workspace**: Dedicated height-bound chat section ensuring fixed header/input controls and smooth auto-scrolling streaming output.

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- A **Google Gemini API Key** (Get one from [Google AI Studio](https://aistudio.google.com/))

### Installation

1. **Clone the repository & navigate to frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root of the `frontend` directory:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173` (or the port indicated in your console output).
